# 包豪斯空间构成海报

将参考图中的空间、图形和文字关系提炼为可迁移规则，再用于用户的新主题。默认用中文向用户说明，**海报和效果图内的文字默认使用西班牙语，标题与副标题都要统一，保留 Ó 等重音符号；用户明确指定其他语言时遵循当次要求**。已有中文或英文样例及其历史提示词只示范构图，复用时须替换为西班牙语。此技能的内置样例是当代转译，不是历史原作复刻。

## 确定参考与转译关系

- 用户只给主题或文字截图时，把它作为创作简报。需要新方向或用户要求搜图时，先网上找有清晰出处的图；选择能分别说明构图和主体结构的参考，记录作者、作品或拍摄信息、来源页面和文件使用标记。不要只收集搜索结果缩略图。
- 用户分批发素材并要求等齐时，收集到用户说发完再开始。
- 对每张输入明确角色：风格参考、主体参考或需要保留内容的编辑目标。不要把截图界面、点赞数、账号信息带入作品。
- 查看 [参考来源与规则](references/source-notes.md)，并实际打开所需参考图。内置海报可示范斜向构图，内置建筑照片可示范体块提炼；它们不限制以后必须用同一主体。
- 保留用户指定的主题、比例、文字和主体身份。提示不足时，先提出一个简短的合理方向并继续；没有必要让用户重复解释已给信息。

## 三种处理方式

**图形构成**：从主题中找到一个可视化关系，例如回响的弧线、速度的方向、平衡的支点。建立一个主构图轴，让圆弧、矩形、直线等相互支撑；更换主体和布局，避免复制参考作品的标志形象与整套位置关系。

**照片几何化**：提炼主体最有辨识度的三个关系，例如长玻璃翼楼、近处立面、后方体块。用少量大色面表达方向、尺度、遮挡；网格只保留必要节奏，清理背景和微小细节。先保证主体可辨，再追求抽象程度。

**摄影与排版**：保留可辨的摄影质感，用单色处理、几何色带和文字建立秩序。照片边界、屋顶线或主体轴线应与文字系统产生联系。图像模型可能重新生成细节；若用户要求照片像素不变，使用保留原照片图层的排版工具，不宣称生成图能保证原样。

## 可复用的设计判断

- 先定主次、方向和负空间，再决定配色。形状要表达主题或结构，避免用圆方三角无目的填空。
- 一张图通常围绕一个主要构成组织，辅以少量线、块或小字。可将约三分之一留白作为起点，密度随主题调整。
- 色彩选两条路线之一：氧化红＋近黑＋灰＋纸白；或红黄蓝＋黑白灰。选一个主色和少量辅色，不强制三原色齐全，也不平均分配面积。
- 文字是构图部件：沿主要方向或网格安排，优先清楚的字形、尺度差异和对比。不要凭空增加历史年份、机构名称、展览日期、作者签名。
- 平面路线用清楚的大色面和克制的印刷纹理。避免渐变、伪旧污渍、浮雕和无来由的立体阴影；摄影路线可以保留真实明暗。
- 将本技能称为“包豪斯启发的当代转译”。不要把包豪斯与蒙德里安视为同义词，也不要把色形对应或三原色当成所有包豪斯作品的硬性规则。

## 生成、对比与交付

使用当前环境的内置图像生成工具；一张输出一个清楚的提示词。工具不可用时说明情况，不把提示词当作已生成图片交付。新主题可参考 [实际提示词](references/prompts.md) 的组织方式，不机械套用其主体或具体摆位。

如果用户没有规定数量，首次探索可生成两到三种有实质差异的处理，随后按反馈收敛。每张生成后检查文字、主体关系、色彩比例、构图和纹理。对明确失败之处做针对性修正。

将网络参考与生成图并排展示，标清二者身份及来源，说明“继承了什么、改变了什么、仍有什么偏差”。两图比例不同时保留完整图并留白，不拉伸或强行对齐；不同作品的风格比较不使用假精确的相似度百分比。

交付图片、提示词、来源记录和简短对比。新生成图保存到当前任务的输出目录。参考 [本次样例评估](references/evaluation.md) 区分已观察结果与期望。打包或本地生成不表示获准向 GitHub 或其他账户上传，发布须遵循用户当次明确决定。


## 西班牙语版材料

当前七张样例的标题和副标题均使用西班牙语。查看 [西语版来源与新建筑候选](references/spanish-sources.md) 了解新增三张参考照片；查看 [实际文字替换提示词](references/spanish-prompts.md) 了解本轮编辑。旧来源和评估记录中的中文标题描述的是历史初版；当前图片以西语预览页为准。


## 新建筑的三种转译

新增样例 05–07 分别验证错位阳台的模块节奏、凹弧转角的连续窗带，以及前后两块立面的遮挡。查看 [实际提示词与观察](references/series-05-07-prompts.md)。当画面语言限定为西班牙语时，检查参考建筑纹样是否被生成成可读的其他语言文字；必要时把这类纹样转译成非文字开孔，并在对比说明中注明改动。不要声称它仍逐细节保留原建筑。


## 发布样张要求

每个对外展示的样品都必须直接包含原图与对应成品。默认原图在上、成品在下；横向更合适时允许左原图、右成品。用完整文件排版，不重画原图，不拉伸或裁切主体。仓库首页也要显示这些对比，不能只放成品。引用类型要标清：风格参考不冒充同一主体的原照。
